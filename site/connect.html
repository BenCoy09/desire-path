Connect your MCP

See what loading all your tools costs on every LLM call, and what routing could save. This runs entirely in your browser: nothing is uploaded.

1. Export your tools

python scripts/export_mcp_tools.py my_tools.json -- npx -y @modelcontextprotocol/server-filesystem /tmp

Replace everything after -- with the command that starts your MCP server (stdio). Repeat per server and paste several files together, or use a client that already prints tools/list.

3. What happens next

Self-host (works today, only tested by us with four bundled servers): save the JSON as data/tools/yourserver.json, rebuild with the Dockerfile, point your agent at /select and send finished runs to /learn. Until it has learned, routing behaves like keyword search, which failed most of our test tasks.
